# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately through [GitHub's vulnerability reporting form](https://github.com/tkalve/ocr/security/advisories/new). Include the affected component, the potential impact, and steps to reproduce when available.

Please do not report unpatched vulnerabilities in public issues or pull requests. If GitHub does not offer the private reporting form, contact the repository owner privately through GitHub and ask for a secure reporting channel rather than posting technical details publicly.

There is no published response-time guarantee. We will coordinate any remediation and disclosure with the reporter.
